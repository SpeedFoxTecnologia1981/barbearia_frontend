# barbearia_frontend
Repositório com o Código FrontEnd do Aplicativo da Barbearia

> Desenvolvido para agendamento de cortes de cabelo com cadastro, login, calendário interativo e notificações.

## 🚀 Tecnologias
- **Angular 18** (Standalone Components, Signals, Router, Forms)
- **TypeScript & CSS Moderno** (Tema Barbearia Premium Dark & Gold)
- **LocalStorage & IndexedDB Database Service** (Persistência completa no navegador)
- **Web Audio API & Web Notifications** (Feedback sonoro e alertas de agendamento)

## 📦 Como Executar
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```
3. Abra no navegador: `http://localhost:4200`
